# Building tools. Making a difference.

We create Android apps that help people navigate life with less stress and more clarity. No data harvesting, no hidden agendas — just honest, useful software built with care.

## When we build

We build when we see a gap — when a tool doesn't exist, or when existing tools feel like they're working against you, not with you.

We build when we can make a difference — even a small one.

## Our apps

**Fotologue** — Built for analogue photographers who wanted to replace the notebook for recording the scene, the settings and the purpose as they shoot. It turned out digital artists needed the same thing, so it works for them too.

*In testing.*

**Distinct Routes** — A safety-first navigator. While other apps focus on getting you there quickly or cheaply, we focus on getting you there — and back — as safely as possible.

*In preparation for release.*
